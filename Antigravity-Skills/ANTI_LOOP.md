# L'ÉCOLE ANTI-LOOP RULES
Before a task, establish what is changing, why, relevant files, what must remain unchanged and how success will be verified.

Do not repeatedly inspect the same files without new evidence. Do not repeatedly attempt the same failed solution. Do not restart completed work.

If an approach fails: Stop → identify why → re-evaluate → choose a different justified approach.

Do not expand scope automatically. If required information is unavailable, stop and request it. Never invent missing information.
