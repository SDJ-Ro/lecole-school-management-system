# L'ÉCOLE PRESERVATION RULES
Before modifying existing code, identify relevant CSS, JavaScript, modules, linked pages, assets/icons, IDs/classes/data attributes, event listeners, API endpoints, storage and PHP dependencies. Do not replace an implementation simply because another looks cleaner.

## Visual Preservation
Unless explicitly requested, preserve dimensions, spacing, typography, colors, icons, positioning, responsive behavior, animations, hover/active states and sidebar behavior.

## Functional Preservation
Verify navigation, buttons, forms, modals, filters, tables, tabs, dropdowns, CRUD, authentication/authorization, API calls, storage and dynamic rendering.

## No Silent Replacement
If an icon, route, asset, library or component is uncertain, investigate rather than inventing a replacement.

## No Scope Creep
Do not combine refactoring with unrelated redesign, renaming, dependency changes or feature additions unless explicitly requested.
