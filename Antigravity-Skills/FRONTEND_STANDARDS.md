# L'ÉCOLE FRONTEND STANDARDS
Use semantic HTML, organized CSS, Vanilla JavaScript, reusable UI components where appropriate, accessible controls, consistent naming and modular feature organization.

Avoid unnecessary libraries, giant global scripts, giant global stylesheets, inline JavaScript where avoidable and duplicated UI implementations.

## CSS
Keep shared/global styles separate from feature-specific styles. Avoid accidental global selectors and unnecessary specificity.

## JavaScript
Separate UI/presentation, coordination, state/data and reusable utilities according to responsibility. Do not split every small function into its own file.

## Accessibility
Preserve and improve semantic structure, labels, keyboard interaction and appropriate ARIA only where needed.
