# L'ÉCOLE DESIGN PATTERN RULES
Use GoF patterns only when they solve an actual problem.

Possible patterns include Factory, Strategy, Observer, Adapter, Facade, Command, State, Template Method and others when justified.

Before introducing a significant pattern, establish:
1. Problem
2. Pattern selected
3. Why it fits
4. Alternatives considered
5. Expected benefit
6. Added complexity

Never use a pattern solely to demonstrate pattern usage. Prefer simple code when a pattern adds no meaningful benefit.
